CINÉDATA

Analyse de données cinématographiques

Présentation du projet

CINÉDATA est un projet universitaire consacré à l'analyse des données cinématographiques. Il vise à étudier les caractéristiques des films et les facteurs associés à leur succès commercial.

Objectifs

  • Étudier les recettes et les caractéristiques des films.
  • Explorer les relations entre différentes variables.
  • Structurer les données dans une base relationnelle.
  • Réaliser des analyses statistiques et des visualisations.

Travaux réalisés

  • Collecte et préparation de données cinématographiques.
  • Nettoyage et structuration des jeux de données.
  • Conception d'une base de données avec SQL et MySQL.
  • Analyses statistiques avec R.
  • Création de visualisations avec Tableau.

Technologies utilisées

R SQL MySQL Tableau
