Ciné Boutique

Projet de développement web autour du cinéma

Présentation du projet

Ciné Boutique est un projet universitaire de développement web portant sur la conception d'un site fictif de vente d'affiches de films.

Ce projet permet de mettre en pratique les notions de développement front-end et de programmation côté serveur.

Objectifs

  • Concevoir une interface web organisée et accessible.
  • Structurer les différentes pages du site.
  • Découvrir la programmation avec PHP.
  • Comprendre la gestion des données avec MySQL.

Fonctionnalités envisagées

  • Catalogue d'affiches de films.
  • Recherche et filtres de produits.
  • Panier d'achat fictif.
  • Espace client.
  • Gestion des données avec une base MySQL.

Ces fonctionnalités correspondent aux objectifs de conception du projet et ne sont pas nécessairement toutes implémentées.

Technologies utilisées et étudiées

HTML CSS JavaScript PHP MySQL
